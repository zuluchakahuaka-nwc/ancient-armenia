# Հին Հայաստան

Քառալեզու (hy/ru/en/pt) անցանց Android հավելված՝ կրթական ուղեցույց Ուրարտուի **Էրեբունի** (մթա 782) և **Թեյշեբաինի** (Կարմիր բլուր) ամրոցներով։

![Էրեբունի ամրոց](app/src/main/assets/wiki_images/erebuni_fortress.jpg)

## Հնարավորություններ

### 🧭 Տուրիստի ռեժիմ
- **Ուղեցույց** — ամրոցների քարտեր լուսանկարներով
- **Վիքի** — հոդվածներ՝ թագավորներ, աստվածներ, կենցաղ, սեպագիր
- **Գրադարան** — գրքեր PDF + աուդիո
- **Urartu.fm** — անցանց կայան. ⏮ ⏯ ⏭, երկար սեղմում = կանգ
- **Քարտեզ** — GPS + ուղիներ քայլելով և մեքենայով
- **Կարգավորումներ** — լեզվի և ոճի փոփոխություն թռուցիկ

### 👤 Աշխատակցի ռեժիմ (PIN)
- **Արագ նկարահանում** — 📷 լուսանկար → նշում հպումներով
- **Աերոհետախուզություն** — կարվածք, ավտոմատ հայտնաբերում, 3D
- **Արտեֆակտների ռեգիստր** — հաշվառում, աուդիտ, հիշեցումներ
- **Արտահանում** — ստորագրված ֆայլ

### 🎨 Դիզայն
- 3 պատմական ոճ (ամեն մեկը = գունապնակ + տառատեսակ + սեպագիր զարդանախշեր)
- Noto Sans/Serif Armenian տառատեսակներ

## Կառուցում

```bash
./gradlew assembleDebug
```

# Древняя Армения / Ancient Armenia

Четырёхъязычное (hy/ru/en/pt) офлайн-приложение для Android: образовательный гид по урартским крепостям **Эребуни** (782 до н.э.) и **Тейшебаини** (Кармир-Блур).

![Erebuni Fortress](app/src/main/assets/wiki_images/erebuni_fortress.jpg)

## Возможности

### 🧭 Режим туриста
- **Гид** — карточки крепостей с фотографиями
- **Вики** — статьи: цари, боги, быт, клинопись
- **Библиотека** — книги PDF + аудио
- **Urartu.fm** — офлайн-станция: ⏮ ⏯ ⏭, долгое нажатие = стоп
- **Карта** — GPS + маршруты пешком и на машине
- **Настройки** — смена языка и скина (Pre-Urartu / Urartu / Post-Urartu) на лету

### 👤 Режим сотрудника (PIN)
- **Быстрая съёмка** — 📷 фото с камеры → разметка тапами
- **Аэро-разведка** — сшивка фото, автодетекция 3 уровней, 3D-реконструкция
- **Реестр артефактов** — учёт, статусы хранения, аудит, напоминания
- **Экспорт** — подписанный файл для ПК

### 🎨 Дизайн
- 3 исторических скина (каждый = палитра + шрифты + клинописные орнаменты)
- Шрифты Noto Sans/Serif Armenian в комплекте
- Стилизация всего экрана: фон + бока + верх/низ + карточки

## Сборка

```bash
# Требуется: Android SDK, Java 21, книги в assets/books/ (см. README там)
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

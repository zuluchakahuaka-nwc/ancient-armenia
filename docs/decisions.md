## Обязательства, вытекающие из решений

- D2 → P5: экспорт = подписанный JSON-дамп + zip фото; импорт с проверкой
  подписи; раунд-трип тестируется e2e.
- D3 → P3: PIN-гейт на входе в режим сотрудника.
- D4 → P3: настройка EXIF в настройках сотрудника.
- D5 → P4: детектор за интерфейсом `ObjectDetector`; реализации:
  `CvHeuristicDetector` (сейчас), `TfliteDetector` (слот).
- D6 → P4: `EraParametricGenerator` (era → параметры → glTF), SceneView-вьюер.
- D7 → P4: схема маркера содержит nullable `registryEntryId` (выключено).
- D8 → P4: экран ручной геопривязки при отсутствии EXIF-гео.
- D9/D10 → P2: секция «Аудио» в Библиотеке: моя музыка / аудиогиды /
  Urartu.fm (тумблер, дефолт ВКЛ, DataStore).
